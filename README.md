### 🛠️ Introduction

DIY Layout Creator (DIYLC) is a specialized software tool designed for hobbyists and electronics enthusiasts to create circuit layouts on stripboard, perfboard, PCB, and point-to-point wiring. 

It provides an intuitive, drag-and-drop interface for placing components, arranging connections, and visualizing circuit designs before assembly. With a built-in component library and customization options, it allows users to design layouts with precision and clarity. 

🎸 **Perfect for pedal builders and tube amp enthusiasts!** DIYLC is particularly useful for designing, analyzing, and debugging guitar wiring diagrams, helping musicians and builders plan and troubleshoot custom wiring configurations for pickups, switches, and controls. Its versatility makes it an ideal solution for DIY electronics projects, prototyping, and documentation.

### ✨ Key Features
* 💻 **Platform Independence:** Runs on any machine capable of running Java JRE/JDK 21 or newer.
* 🖱️ **Intuitive UI:** Easy-to-use interface; most operations can be done seamlessly with a mouse.
* 🎛️ **Versatile Designs:** Draw PCB, perfboard, stripboard, or point-to-point layouts, schematics, guitar wiring diagrams or custom faceplates.
* 🔌 **Highly Extensible:** API allows custom plug-ins and new components to be added easily.
* 🚀 **Optimized:** Improved performance and reduced memory consumption.
* 💾 **Smart Defaults:** Save default values individually for each component property.
* 🖨️ **Export Options:** Export outputs to image, PDF, or printer.
* 📄 **Toner Transfer & Gerber:** Export PCB trace masks for toner transfer or Gerber files for fabrication.
* 📋 **Bill of Materials:** Create a BOM within the project or export to multiple file formats.
* 🔍 **Guitar Wiring Analysis:** Analyze guitar wirings and visualize detailed pickup configurations for each switch state.
* ☁️ **Cloud Integration:** Share your projects, search the cloud, and download other users' designs.
* 🤖 **AI Powered:** Features a built-in AI assistant to help answer general electronics questions, guide you through DIYLC's usability, and provide insights or troubleshooting for the specific circuit you are designing.
* ⚡ **Circuit Analysis:** Various tools aimed to help you debug and analyze your circuits.
* 📈 **SPICE Netlists:** Export circuits directly to SPICE-compatible netlists.
